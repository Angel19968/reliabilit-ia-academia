# RELIABILIT-IA Academia

Página de la comunidad de clases y asesorías de **Inteligencia Artificial aplicada al mantenimiento
industrial y minero**, dictadas por profesionales en actividad. Nace del trabajo de construcción de
talleres internos (IA aplicada a mantenimiento, sistemas digitales para minería) y se abre como
comunidad pública.

Sitio estático (HTML + CSS + JS, sin build step), pensado para desplegarse directo en **GitHub Pages**,
manteniendo la misma identidad visual de [RELIABILIT-IA](https://angel19968.github.io/reliabilit-ia/)
y del [portafolio de Miguel Cayllahua](https://angel19968.github.io/miguel-cayllahua/).

## Estructura

```
/index.html     Página única: hero, comunidad, temario, cómo funciona, próxima clase, contacto
/style.css      Estilos (mismo sistema de variables/paleta que reliabilit-ia y miguel-cayllahua)
/script.js      Barra de progreso de scroll, estado del nav, menú móvil
/assets/        Favicon
```
